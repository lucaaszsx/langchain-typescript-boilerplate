# Products & Services

## UI/UX Design

Complete interface design for web applications, from wireframes to high-fidelity prototypes.

- User flow mapping
- Wireframing and low-fidelity prototypes
- High-fidelity screen design (Figma)
- Interactive prototyping for stakeholder validation
- Usability review and accessibility recommendations

## Front-End Development

Implementation of designed interfaces using modern technologies, ensuring responsiveness and performance.

- HTML5, CSS3, and JavaScript
- React and Next.js
- Integration with REST APIs
- Cross-browser compatibility
- Performance optimization

## Design System

Creation of a reusable component library to ensure visual consistency across the product.

- Component documentation
- Typography, color, and spacing tokens
- Figma component library
- Front-end implementation of core components

Available as an add-on to the Professional and Enterprise plans.

## UX Audit

Structured analysis of an existing interface to identify usability problems and improvement opportunities.

- Heuristic evaluation
- User journey analysis
- Written report with prioritized recommendations
- Optional follow-up meeting to present findings

Available as a standalone service.
